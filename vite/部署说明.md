# 沪深股市实时行情与分析页面 — 部署说明（阿里云轻量应用服务器）

本部署包共 2 个文件：

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本体（单文件，已内联全部样式与脚本，无任何外部依赖） |
| `deploy.sh` | 服务器端一键部署脚本 |

部署目标：已有 Web 服务（Nginx / Apache / 宝塔）的 Linux 服务器，页面将部署为现有站点下的子目录 `<站点根>/stock/`，**不改动任何现有站点配置**。

---

## 一、上传文件到服务器

在本机（Windows PowerShell）执行，把两个文件传到服务器任一目录（示例 `/root/stock-deploy/`）：

```powershell
ssh root@www.studytech.cloud "mkdir -p /root/stock-deploy"
scp vite/index.html vite/deploy.sh root@www.studytech.cloud:/root/stock-deploy/
```

> 使用宝塔面板的用户也可以：登录宝塔 → 文件 → 进入任意目录（如 `/root`）→ 上传这两个文件。

## 二、执行一键部署

SSH 登录服务器后：

```bash
cd /root/stock-deploy
chmod +x deploy.sh
sudo ./deploy.sh
```

脚本会自动探测站点根目录（宝塔 `/www/wwwroot/...` → Nginx 配置 root → Apache → 兜底 `/var/www/html`），并将页面部署到 `<站点根>/stock/index.html`。

预期输出示例：

```
[信息] 自动探测站点根目录: /www/wwwroot/your-site
[成功] 部署完成: /www/wwwroot/your-site/stock/index.html
访问地址: http://www.studytech.cloud/stock/
```

如果自动探测的目录不对，直接手动指定站点根目录重跑：

```bash
sudo ./deploy.sh /www/wwwroot/你的站点目录
```

## 三、访问验证

浏览器打开 `http://www.studytech.cloud/stock/`（站点已配置 HTTPS 证书则用 `https://`），检查：

- [ ] 顶部 4 个大盘指数卡片有数据（上证指数 / 深证成指 / 创业板指 / 科创50）
- [ ] 自选股表格显示行情，右上角刷新倒计时正常走动
- [ ] 搜索框输入「茅台」出现候选下拉，可添加到自选
- [ ] 点击任一股票「分析」→ 出现K线图、技术指标打分表与综合结论
- [ ] 刷新页面后自选股仍在（浏览器本地保存）

## 四、HTTPS 说明

- 行情数据全部由**访客浏览器**直接调用东方财富 https 接口（JSONP），与服务器无关
- 页面本身是纯静态文件：站点已有证书则 `https://www.studytech.cloud/stock/` 直接可用，无混合内容告警；只有 HTTP 也同样可用

## 五、更新升级

修改本地 `index.html` 后重新部署即可（脚本自动备份旧版）：

```powershell
scp vite/index.html root@www.studytech.cloud:/root/stock-deploy/
```

```bash
cd /root/stock-deploy && sudo ./deploy.sh
```

回滚旧版：

```bash
cp <站点根>/stock/index.html.bak-时间戳 <站点根>/stock/index.html
```

## 六、故障排查

| 现象 | 原因与处理 |
|---|---|
| 访问 404 | 脚本探测的站点根目录不对 → `sudo ./deploy.sh /正确的站点根目录` 重跑；或用 `nginx -T \| grep root` 查看实际站点目录 |
| 页面能打开但行情空白 | 行情是访客浏览器直连东方财富接口，检查**访客网络**能否访问公网；点击页面顶部若出现「行情刷新失败」提示，多为瞬时网络问题，等待下一轮自动刷新 |
| 服务器本机 curl 正常、外部打不开 | 阿里云轻量服务器控制台 → 防火墙/安全组，确认已放行 80（和 443）端口 |
| 想让 `http://域名/` 直接打开本页面 | 把部署子目录改为根目录：`sudo ./deploy.sh` 后手动将 `<站点根>/stock/index.html` 复制为站点首页（注意备份原首页），或保持 `/stock/` 子路径访问 |
| 新增自选股刷新后丢失 | 浏览器无痕模式 / 禁用了 localStorage → 换普通模式访问 |
